02 / 09
The pattern

Every one of these companies had the same owner doing every job.

Travel agent, shipping coordinator, sales, accounts, support — one person, across every venture, in two countries. That was sustainable at small scale. It stops being sustainable the moment there are eight companies under one holding structure, run by the same one person.

That's the actual problem TRoyAI was built to solve — not a general AI ambition, but a direct answer to twenty-five years of doing everything personally.

04 / 09
The build — TRoyGO™

Taking the same template back to where it started: travel.

Then

Troy Travel Agency, run by hand — one owner handling bookings, guides, itineraries, and client relationships directly, first in Turkey, then rebuilt in Australia.

Next

TRoyGO™ — an unmanned, AI-agent-run travel agency using the exact department/agent structure proven in TRoyAI, applied to twenty-five years of real travel and logistics know-how instead of a generic template.

Live at troytravelagency.com — real infrastructure, not a mockup

TRoyGO™ runs on a real Postgres database, not placeholder data — bookings, owner approvals, and a partner-application system (with real file uploads) for outside travel experts to apply and be reviewed, all backed by an owner-only admin dashboard. It runs its own daily research agents finding genuine hotels, rental cars, tour packages, and cruises, and queries Duffel's real flight API directly for live pricing and routes.

Flights are still in Duffel's test mode pending business verification — the company's real ABN (30 302 098 137) is now active, with a formal "TROYGO" business name registration in progress, which is what unlocks live flight data.

New — Travel Guide, live in 5 cities

Darwin, Istanbul, Tokyo, Bangkok and Sydney each now have a dedicated guide page with a genuinely live "[City] Today" block — real current temperature, UV index and sunrise/sunset, pulled hourly from free public weather APIs, not a static number. Each page pairs that with a real evergreen events calendar and cross-links straight into TRoyGO's actual bookable packages and hotels for that city.

Built on one shared engine, so adding another destination is now a small, fast addition rather than a rebuild.

Real currency, real reviews policy

Prices across the site — packages, hotels, flights, cruises, and agent tour listings — now convert live to EUR, GBP, JPY, CAD, AUD and AED, replacing what had been a hardcoded USD-only display in several places.

The two blocks of fabricated traveler reviews on package and agent pages are gone. In their place: an honest "no reviews yet" state, or — where a real aggregate rating exists from a booking partner — that real number, clearly sourced, with no invented names or quotes attached.

07 / 09
TRoyVibe™ — from prototype to production

Teaching agents — and people — to actually understand each other.

TRoyAI's departments already shared knowledge with each other, but what actually got shared was a raw, unstructured wall of text — no explicit intent, no confidence marker, no honest flag for "this part is uncertain." TRoyVibe™ started as the fix for that.

It's no longer just a converter sitting outside the agency. TRoyVibe™ now gates every brief that reaches TRoyAI's CEO Assistant: raw input is read for real intent and confidence first, and anything short of "clear" gets a genuine clarifying question back — not a guess — before any department is delegated work.
